# Boosters

Compatible additions that make any technique in the notebook stick harder. None of them replaces or
competes with a notebook method; each adds a new route to the same memory (the notebook rule in
SKILL.md). Most help learners who struggle to visualise.

| Booster | How to use it with the notebook methods | Evidence |
|---|---|---|
| **Draw it** | Sketch each picture for a few seconds before placing it at its locus. Bad drawings work. | The drawing effect: drawing beats writing a word out repeatedly (Fernandes, Wammes & Meade). |
| **Say it aloud** | Speak each item as you link or place it, then walk the palace aloud when recalling. | The production effect: spoken items are remembered better than silent ones (MacLeod). |
| **Act it out** | Mime the interaction: the monkey snatching the sausage, Mike tapping the microphone on his nose. | The enactment effect: acting out phrases improves recall of them. |
| **Ask why** | For each fact placed in a palace, add the reason it's true to the scene. | Elaborative interrogation (moderate utility in Dunlosky et al., 2013). |
| **Mix it up** | In drills, interleave kinds (`gen cards`, then `gen numbers`, then `gen names`) instead of one long block. | Interleaving improves telling cases apart and long-term retention. |
| **Change the room** | Review palaces in different physical places so recall doesn't depend on where you learned it. | Context-dependent memory (Godden & Baddeley); varying context helps transfer. |
| **Learn lines like an actor** | For speeches and scripts: one point per locus, then ask "why am I saying this here?" for each. | Actors' active-experiencing technique (Noice & Noice). |
| **Sleep on it** | Learn hard material in the evening and review it the next morning. | Sleep consolidates memories. |
| **Rest after learning** | 5–10 minutes of quiet, eyes closed, no phone, straight after an encoding session. | Wakeful rest improves later recall (Dewar et al.). |
| **Move** | Regular aerobic exercise. | Linked to hippocampal health and memory. |

**Coaching:** offer one or two boosters when a learner keeps missing items despite good images,
or can't visualise. Never stack them all at once.
